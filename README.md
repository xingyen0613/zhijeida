# smart-bopomofo

macOS 注音輸入法的中英混輸判別器。目標是在中文輸入狀態下直接打英文，由輸入法判斷該串按鍵是中文還是英文單字，免去手動切換。

對標 Windows 上的華碩智慧輸入法（macOS 無官方版本）。

## 現況

Phase 1：離線判別器（本階段）。判別邏輯獨立於輸入法，用命令列驗證規則正確性。
Phase 2：接上 IMK。預計 fork McBopomofo（MIT），只加判別層，不重寫注音引擎。

## 關鍵前提

判別規則建立在以下打字習慣上：**會打聲調，一聲直接按空白鍵**。

因此每個中文音節結束時必有一個非字母鍵（聲調鍵或空白），而一個注音音節最多 3 個符號。這讓「連續 4 個以上字母」成為英文的確定訊號。

不打聲調的使用者不適用本規則，需要另一套基於語言模型的做法。

## 可行性數據

以英文前 111 個高頻詞測試（大千鍵盤佈局）：

| 分類 | 佔比 |
|---|---|
| 長度 >=4，中文不可能產生，零歧義 | 46.8% |
| 長度 <=3 且非合法音節，可判英文 | 46.8% |
| 長度 <=3 且是合法音節，真歧義 | 6.3% |

真歧義只剩 7 個詞：`do`=ㄎㄟ `go`=ㄕㄟ `i`=ㄛ `no`=ㄙㄟ `so`=ㄋㄟ `to`=ㄔㄟ `up`=ㄧㄣ

未驗證項目：這 7 個注音的**一聲**是否有常用字。若無，真歧義可再降。需要帶聲調的權威注音字表才能確認。

另以 /usr/share/dict/words 全字典 19.7 萬詞測試，整體衝突率上界 6.86%（寬鬆音節規則）。

## 使用

```bash
python3 judge.py samples/example.txt
```

測試資料產生方式：切到英文輸入法，照平常中英混打的方式打一段（中文部分照打注音鍵位，英文部分照打英文），存成 txt。

`samples/*.txt` 不進版控（可能含個人輸入內容），僅 `example.txt` 例外。
